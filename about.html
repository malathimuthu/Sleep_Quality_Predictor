ℹ️ About Sleep Quality Predictor

Project Overview

Sleep Quality Predictor is an Artificial Intelligence and Machine Learning based web application. It predicts whether a user's sleep quality is Good or Poor based on sleep hours and provides useful health recommendations.

Main Features

🌙 Sleep Quality Prediction
🤖 AI Based Recommendation
📊 Dashboard Analytics
📜 Prediction History
💻 Responsive Web Design
